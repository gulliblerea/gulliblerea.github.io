## ⚠️ 三条安全边界（别跳过）

- **只在 App Store 登录，绝对不要登 iCloud**。锁机的唯一成因是登录位置错了，与账号是否共享无关。一旦在「设置 → 你的名字」登录他人账号并开启「查找我的 iPhone」，对方就能远程锁定设备。
- **不要在共享账号上充值或绑定支付方式**。余额和内购记录都不属于你，且可能被其他使用者动用。
- **下载完立刻退出**，不要把共享号当自己的长期账号经营——它随时会被系统轮换或收回。

完整的安全操作与误登录补救见[安全使用指南](https://gulliblerea.github.io/-id-/safe/)。

## ❓ 常见问题

**Q：这个仓库为什么不直接放账号密码？**
共享账号密码由系统定期轮换，写死在文档或截图里的密码从发布那一刻就在过期。实时页永远给的是此刻有效的密码，这也是为什么本仓库只做索引、不存密码。

**Q：免费共享号和独享号到底差在哪？**
免费号多人共用、随时可能被他人改动或被风控收回，适合"下载一次就走"；独享号只有你使用、可自行改密码、可绑支付，适合长期。成本对比见[这篇](https://gulliblerea.github.io/-id-/shared-id/)。

**Q：下载了小火箭还需要付费吗？**
不需要。共享账号本身已购买过该应用，登录后看到云朵图标即可直接下载，不会产生扣费。

**Q：账号会突然失效吗？**
会。共享号同时被多人使用，触发 Apple 风控属于常态，不是账号质量问题。处理方式是换一个号，**不要在同一账号上反复试**——重复失败会加重风控。

**Q：为什么不建议频繁切区？**
切区需要目标区地址与支付方式，频繁切换容易触发风控。需要多个区就用多个账号，别在一个号上反复切。
